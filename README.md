# research-harness-simple

A simpler research harness that adapts to a broad discipline.

## Overview

`research-harness-simple` aims to be a lightweight scaffold for running research
workflows. It stays small enough to understand at a glance and flexible enough
to fit different fields, so you don't need a separate tool for each discipline.

## Status

Early development. The project structure, interfaces and usage instructions
will be added here as they take shape.
